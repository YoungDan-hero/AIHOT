# 短剧前线

以国内为主、兼顾出海和海外动态的短剧行业资讯站。两个市场采用同一套事实、时效和从业价值标准，追踪真人短剧、AI 漫剧与竖屏微短剧的发展，将多源报道归成事件，整理中文摘要并编成日报。

基于 [AIHOT 开源框架](https://github.com/KKKKhazix/AIHOT) 定制。技术栈为 Node.js 24、TypeScript、React Router、Fastify、PostgreSQL 与 pg-boss；代码遵循 [MIT 许可证](LICENSE)，字体许可见 [NOTICE](NOTICE)。

## 当前内容范围

| 分类 | 收录范围 |
|---|---|
| 国内动态 | 中国大陆市场的平台、剧目、制作、商业与政策进展 |
| 海外动态 | 海外市场的平台、制作、发行、商业合作与本地化进展；中国企业出海按发生市场归类 |
| 跨市场观察 | 同时涉及多个市场的行业研究、比较与共同趋势 |

国内、海外并列展示和筛选，不按来源语言、国别或企业所在地加减分，也不强行凑足相同的新闻数量。资讯保留原文链接，外语内容整理为中文摘要。

## 当前接入信源

当前启用 **200个信源：国内150个、海外50个**，另保留1个暂停配置（雷峰网生产复采频繁超时），使用豆包进行相关性筛选、评分、摘要与归组。国内来源占75%，两个市场保留相同事实与价值标准。

来源包括短剧自习室、新腕儿、新榜、界面、钛媒体、中国新闻出版广电报、广电总局和地方广电、中文在线，以及C21、Television Asia Plus、Tubefilter等。完整入口、选择器与频率见 `industry/sources.json`，运行方法见[短剧站说明](docs/short-drama.md)。

综合信源先用行业关键词过滤标题、摘要与已获取正文，再交给豆包；新源首次最多回溯6条。新增网页源要求可信日期，防止未定日期旧链接在后续轮次进入模型队列。站内只展示摘要和原文链接；同稿转载和聚合报道要保留原始出处。

新源在短时两轮列表及两篇正文/日期检查后接入；当前列表没有行业稿时，用同主体历史行业原文验证正文与日期，保持新稿关键词过滤。启用监测数与本轮产出相关资讯的来源数分别统计，200个源不代表每天200篇资讯。受限或停更入口保留在待验收名单，不计入启用数。持续成功率仍需运行观察。

## 本地启动

需要 Node.js **24.22.1 或以上**、PostgreSQL 17，或使用 Docker Compose。项目不包含模型密钥；自动筛选、写作和部分正文补抓需要在后端配置相应服务。

1. 安装依赖：`npm ci`。
2. 按 [部署文档](docs/deploy.md) 准备 `.env` 与数据库；使用自己的管理员密码、随机密钥和模型配置，不提交 `.env`。
3. 执行数据库迁移，分别运行 `npm run dev:api`、`npm run dev:web`。本地网页地址为 `http://localhost:3000`，后台为 `/admin`。
4. 检查信源与模型配置后，再按 [短剧站运行说明](docs/short-drama.md) 启动 worker。开发验证时保持采集、模型和推送开关关闭。

完整 Docker、HTTPS、代理和备份配置见 [部署](docs/deploy.md)。已有部署切换行业时，seed 不会自动覆盖或停用旧信源；先在后台检查旧 AI 信源，保留历史内容并按需要暂停旧源。

## 验证与校准

```bash
npm run typecheck
DATABASE_URL=postgres://127.0.0.1:5432/duanju_test npm test
npm run build -w @aihot/web
npm run test:web
node scripts/smoke.ts --base http://localhost:3000
```

测试数据库名称必须以 `_test` 或 `_ci` 结尾。测试不得调用真实付费模型或推送服务。

筛选标准在 [`industry/prompts/`](industry/prompts/)，门槛在 [`industry/selection.ts`](industry/selection.ts)。当前门槛仍需使用短剧人工标注样本校准，不能据代码检查认定筛选准确率。运行与接入边界见 [短剧站运行说明](docs/short-drama.md)。
