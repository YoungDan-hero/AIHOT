# 短剧前线行业包

以国内短剧资讯为主，兼顾出海与海外市场，覆盖真人短剧、AI短剧与AI漫剧。事件按主要市场分为“国内动态”“海外动态”“跨市场观察”，内容形态、制作、发行、商业和规则由标签表达；信源语言和公司国籍不决定所属市场。

| 文件 | 当前用途 |
|---|---|
| `taxonomy.ts`、`topics.json` | 市场分类、内容标签、平台与机构主题，以及标题主体核对 |
| `sources.json` | 首次启动导入的已验收信源；国内优先；已有数据库的信源在后台管理 |
| `prompts/` | 短剧相关性预筛、同标准评分、中文摘要、事实抽取、跨语言归组和报告写作 |
| `selection.ts` | 暂沿用引擎分级门槛，国内海外相同；未使用短剧金标校准 |
| `*.example.jsonl` | 虚构的评测格式示例，用于说明样本结构，不能证明实际筛选准确率 |

评分保留七类内容、五维整数加权、噪声压制和不可信素材边界。优先有具体事实、适用范围和从业价值的变化，压低课程招商、招募广告、无来源战报和演员私生活。播放量、下载量、热力值、流水、收入与利润分别核对，估算数字保留口径。

上线前按[精选与校准](../docs/selection.md)准备使用者标注的国内及海外样本，校准门槛与评分提示词。现有数字是启动基线，不代表已达到短剧行业的准确率。信源默认只公开摘要和原文链接，全文展示与再分发开关保持关闭。
