# 短剧前线运行说明

本站面向短剧从业者，以国内市场为主，兼顾海外市场。按发生市场分为“国内动态”“海外动态”，跨市场研究和共同趋势进入“跨市场观察”。真人短剧、AI 漫剧和竖屏微短剧均在范围内；相同事实与价值采用相同标准，不设地域加分或固定数量配额。

扩容批次每源首次最多回溯 2 条，首次采集按每分钟最多 12 个新源错峰到期，后续由原有调度根据近期产量调整频率。网页源需要可信文章日期，历史文章按原文时间归档。

综合来源先用 `ingestNoiseFilter.requireMarkers` 过滤，豆包再判断行业相关性、评分、整理摘要和归组。评分阈值不因地域改变，不设国内外资讯配额。

扩源范围限于短剧和新媒体。短剧专门信源不足时，核验与内容生产、平台规则、投流分账、创作者运营或出海发行直接相关的 MCN 和新媒体来源。优先选择平台公开公告、创作者运营资料、原创行业研究和独立采访。通用公司新闻、泛科技、娱乐八卦和以转载为主的重复入口不作为补充来源。

依赖未配置的公众号付费接口、登录、异常HTTP/TLS或不能确认列表/日期/正文的入口不计入启用数。36氪原RSS继续运行，新作者接口批量验证触发403后保留待验收。流媒体网使用公开匿名会话列表接口；鞭牛士和新腕儿使用原生POST列表。个别官方站点采用其公开导航明确标注的HTTP地址，TLS、地址与跳转校验保持开启。

公开请求对新源域名至少间隔2秒，Marketing Dive为5秒；API和worker共享域名节奏。默认只显示摘要与原文链接，站内全文和全文RSS关闭。

## 启动

1. 使用 Node.js 24.22.1 或以上、PostgreSQL 17，安装依赖并按 `docs/deploy.md` 准备 `.env`。模型接口、域名、管理员密码与随机密钥由部署者填写；不在仓库保存真实凭据。
2. 先启动数据库、API 和网页，检查站名、国内/海外分类与后台。开发环境保持 `COLLECT_ENABLED=false`、`MODEL_CALLS_ENABLED=false` 及所有推送开关关闭。
3. 后台检查当前信源；已有数据库还需检查并暂停不再使用的 AI 示例源。seed 只补缺失信源，不自动更新已存在的同 ID 配置，也不删除历史文章。
4. 确认模型配置和预算后再开启采集、模型并启动 worker；公开域名与 HTTPS 按部署文档配置。首次历史导入按原文时间归档，不应当作当天新增资讯。

`DEPLOYMENT.publicFetchIntervalsMs` 对新源设置 2000 毫秒、Marketing Dive 设置 5000 毫秒的公开请求起点间隔，API 与 worker 共用同一域名许可。裸域与 `www` 归入同一桶。正式环境不要绕过该入口发送同域采集请求。

海外信源需要代理时，在 `.env` 配置已有的 `EGRESS_PROXY_URL`，重启 API 与 worker。后端不会自动采用终端的 `HTTP_PROXY` 或 `HTTPS_PROXY`；终端工具能访问，不代表后端已走同一路径。TLS 证书和目标地址检查保持启用。

本机代理的 `127.0.0.1` 地址仅供同一主机上的 Node 进程使用。Docker 容器中的 `127.0.0.1` 指向容器自身；容器部署应改成容器可达的代理地址（Docker Desktop 可按宿主代理设置使用 `host.docker.internal`），并分别核对 API、worker 的网络连通性。Docker 默认配置不内置代理。

## 豆包火山方舟

默认接口为 `https://ark.cn-beijing.volces.com/api/v3`，默认模型为 `doubao-seed-2-1-pro-260915`。在 `.env` 填入 `LLM_API_KEY`，保留 `LLM_EXTRA_JSON={"thinking":{"type":"disabled"}}` 和 JSON 模式即可复用现有 OpenAI 兼容调用。所有筛选、两次评分、摘要与归组步骤默认使用这一模型；无需额外 SDK。

账号可用模型可通过方舟 `GET /api/v3/models` 查询，模型是否可用以该账号的返回为准。调用继续经过现有付费回执与预算熔断；不要在文档、日志或版本库保存密钥。官方说明：[鉴权与 Base URL](https://docs.volcengine.com/docs/ark/base-url-and-authentication?lang=zh)、[结构化输出](https://docs.volcengine.com/docs/ark/structured-output-beta?lang=zh)。

每日 08:00 出日报，每周一 10:00 出周报，每月 1 日 10:30 出月报，均为北京时间；设置位于 `site/site.ts` 的 `EDITION_TIMES`。

## 检查与校准

软件检查命令：

```bash
npm run typecheck
DATABASE_URL=postgres://127.0.0.1:5432/duanju_test npm test
npm run build -w @aihot/web
npm run test:web
node scripts/smoke.ts --base http://localhost:3000
```

测试库名必须以 `_test` 或 `_ci` 结尾。自动测试采集、模型与推送使用本地假服务，不调用真实付费服务。

评分保留原有内容类型、五维加权和噪声压制结构；现有数字是待校准起点。请用国内与海外都有覆盖的人工标注样本运行 `scripts/eval-selection.ts`，检查广告误入、重要公告漏选、术语翻译、同事件去重及地域偏差，再决定正式门槛。未经此项评测，不宣称短剧筛选准确率。

接入后应持续观察成功率、日期一致性、新文延迟和列表窗口漏采。页面打开不触发模型调用；采集和模型任务运行在后台 worker，实际处理费用取决于后端服务与预算配置。

## 对外发布前

站点默认展示摘要与原文链接。站内全文和全文 RSS 需要来源授权。

采集和模型是否开启，以实际后端环境与后台状态为准。本次本机验收使用豆包并启用持续采集。公网部署和对外推送需另行配置。
